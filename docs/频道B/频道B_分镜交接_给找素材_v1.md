> 这份单子把「内容分镜」这一摊完整交给你，工具和字段都在这里，不用回头问。

## 一、你负责的（内容分镜）

按脚本逐句决定每一镜是哪种类型，写进分镜表：

| 列 | 取值 | 说明 |
|---|---|---|
| `类型` | `录屏` / `字卡` / `动效` / `图形` | 四选一；录屏=证据，字卡/动效=解释与节奏 |
| `要点数据` | 数值＋单位＋对比值 | 例 `成本对比：789 元 vs 300+元/月 ≈3 个月追平`；**没核实写「待补·未核」，不许编** |

内容规则（你自己判断，不用问编剧）：
- 关键数字/术语 → 数字卡（滚动 + 单位 + 一行出处）；
- 逻辑对比、进度、重试次数 → 对比条 / 进度条；
- 概念、流程、架构（ERP 结构、工具链、类目判断逻辑）→ 图形动画逐元素入场；
- **禁止纯字幕空屏**；录屏里一晃而过的数字（报价、会员费、单图成本）要单独拉出来做卡；
- 数字类台词**全片只出一张卡**，同一个数不重复推。

## 二、工具与命令（工作区根目录，直接用）

```bash
python scripts/逐句卡点表.py <集号>_scene_plan.json --out <集号>_逐句卡点对照表.csv     # 一句一条字幕+预计起止+对应镜号
python scripts/导出分镜表.py <集号>_逐句卡点对照表.csv <集号>_scene_plan.json \
       --overlay <集号>_叠加层清单.csv --out <集号>_分镜表.csv                 # 出 7 列分镜表
```
`叠加层清单.csv` 两列：`触发句,类型,要点数据`——用句子关键词匹配到分镜行，命中不到的会打 ⚠ 提示。

`scene_plan.json` 用 `scripts/分镜导出.py` 从 md 生成（`picture` 写画面槽），改完 md 后重跑一次即可。

## 三、交给视频制作前自检

1. 分镜表**一句一行**，行数 = 纯口播句数（`channelB/check_shot_table.py` 必须 PASS）；
2. `类型` 四值之外没有别的值；`要点数据` 里没有「待补」以外的不明数值；
3. 分镜表文件名固定 `<集号>_分镜表.csv`，与纯口播同前缀。

## 四、编剧（我）接手的部分

1. **选题卡**：用户口述 → 5 字段卡；
2. **排期表**：这集拆到天（交稿/录屏/剪映配音/质检/发布）；
3. **节奏技术**：`切点表.csv`（每 ≤8s 一个变化点、渲染色镜 ≤20s）、连续录屏 ≤3 句必须插卡/放大/切源、逐句卡点对照表复核；
4. **收稿检查**：字数 1500–1750、一句一行、数字汉字、编号不断句、型号拆写、名词串拆开、读法表、事实出处、铁律一句。

**交界规则**：内容分镜有争议（哪段该录屏、哪段该做卡）→ 你定；节奏问题（太静、切点不够、卡顿）→ 我定；一次只退一个人。
